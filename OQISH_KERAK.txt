VERCEL'GA QANDAY YUKLANADI (bepul, birinchi marta):
-----------------------------------------------------

A) vercel.com ga kiring -> Sign Up (email yoki GitHub bilan).

B) Shu papka ichida terminal oching:
   - Windows: papka manzil satriga "cmd" yozib Enter.

C) Terminalga yozing:
      npx vercel
   So'rovlar chiqadi:
      - Log in?          -> Enter, brauzerda ruxsat bering
      - Set up & deploy? -> Y
      - Project name?    -> Enter
      - Framework?       -> Other
      - Root directory?  -> Enter (nuqta .)
      - Deploy?          -> Yes

D) Oxirida manzil chiqadi, masalan:
      https://vercel-app-abc123.vercel.app
   SHU MANZILNI NUSXA OLING va botga yuboring:
      /setwebapp https://xxxx.vercel.app
   (shundan keyin Telegram menyudagi "Mini App" tugmasi ochiladi)
